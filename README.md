# E-commerce Website

A Daraz-style ecommerce demo with:
- storefront homepage
- login and signup flows
- cart and checkout experience
- admin panel for managing products and orders
- user dashboard for order history

## Features
- Product listing and browsing
- Authenticated user and admin flows
- Cart and order placement
- Responsive storefront UI

## Run locally
`ash
npm install
node server.js
`

Open http://localhost:3000

## Deployment
This project is configured for Vercel with serverless API routes under the api folder.
